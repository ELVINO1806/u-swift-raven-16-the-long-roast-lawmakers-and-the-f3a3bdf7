## Entry

This program writes a single satirical sentence to `/output/entry.txt`. The sentence roasts lawmakers who write sweeping rules for algorithms and the internet while being unable to perform the most basic file operation themselves — turning a document into a PDF. The joke lands on the gap between the authority they claim over technology and the competence they show with it.

The roast stays deliberately narrow: one concrete scene, fully committed, instead of a broad complaint. A bill about algorithms that its own authors cannot explain, and an hour lost to a file conversion that an intern has to rescue, says more about the premise than any list of grievances could. The humor is in the contrast — the people regulating the future of the internet, defeated by the "Save as PDF" button.

## Run

```sh
python3 main.py
```
