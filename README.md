## Entry

This program writes a single satirical sentence to `/output/entry.txt`. The sentence roasts lawmakers who write sweeping rules for algorithms and the internet while being unable to handle the simplest everyday file task themselves — the gap between the authority to regulate technology and the competence to operate it.

The joke works by setting up the grandeur first — a law, passed, on algorithms — and then undercutting it with something small and humiliating: an hour lost to a file conversion, outsourced to an intern. Power on one side of the comma, helplessness on the other.

## Run

Run `python3 main.py` and read `/output/entry.txt`.
